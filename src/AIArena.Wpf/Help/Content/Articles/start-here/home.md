AI Arena is a native Windows app for structured conversations between local or OpenAI-compatible language models. This Help Center is task-based: choose the outcome you need, then follow the linked article.

> **Private by design:** The Help Center is packaged with the app and works offline. Opening or searching help does not call a provider, change a session, or enable Internet access.

## Five ways to use the app

- **First-time user:** complete Quick Start before changing advanced settings.
- **Returning operator:** open the saved session, inspect Status Center, then use 1 Turn before Auto Chat.
- **Model evaluator:** hold the scenario and causal context constant; change only the route or model under test.
- **Agent user:** select a trusted workspace, preview commands, and verify the resulting files.
- **Advanced user:** use Experiment Lab and the authenticated PowerShell control plane for repeatable local evidence.

## The core distinction

A model can be **available**, **loaded**, **configured**, and **assigned** independently. Loading affects provider residency. Assignment affects which role receives a model. A loaded model does not make Arena Controls ready unless routing is also complete.

Use the Universal Status Center for cross-app outcomes. It keeps the newest four meaningful rows visible beneath Arena Controls and opens a bounded current-run history dashboard when selected.
