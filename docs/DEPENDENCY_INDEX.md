## Notes

- Service-like types are classes, interfaces, or record classes whose names end with `Service`, `Store`, `Client`, `Mapper`, `Selector`, `Config`, `Provider`, `Settings`, or `Palette`.
- Constructor dependencies are a static source scan. Manually created dependencies inside method bodies are intentionally not treated as injected dependencies.
- Re-run with `.\scripts\dependency-index.ps1 -Check` before a release gate; it fails when the checked-in index is stale.
